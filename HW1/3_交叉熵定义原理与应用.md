# 交叉熵的定义、原理与应用

## 一、定义链条

### 1.1 信息量

事件 $x$ 发生的概率越小，携带的信息越多；独立事件的信息量应可加。满足这两条的函数唯一是

$$I(x)=-\log p(x)$$

验证可加性：$I(x,y)=-\log[p(x)p(y)]=I(x)+I(y)$。以 $e$ 为底时单位是 nat，以 2 为底时是 bit。

### 1.2 信息熵

对随机变量取平均，得到熵：

$$H(p)=-\sum_x p(x)\log p(x)$$

它表示不确定性的度量，也表示按分布 $p$ 生成的数据用最优编码所需的平均长度。$k$ 个取值的分布满足 $H(p)\le\log k$，等号在均匀分布时取到。

### 1.3 KL 散度

衡量两个分布的差异：

$$\mathrm{KL}(p\Vert q)=\sum_x p(x)\log\frac{p(x)}{q(x)}\ \ge\ 0$$

非负性证明：由 $\log t\le t-1$，

$$-\mathrm{KL}(p\Vert q)=\sum_x p(x)\log\frac{q(x)}{p(x)}\le\sum_x p(x)\left(\frac{q(x)}{p(x)}-1\right)=\sum_x q(x)-\sum_x p(x)=0$$

注意 $\mathrm{KL}$ 不对称，不是距离。

### 1.4 交叉熵

用分布 $q$ 去编码来自分布 $p$ 的数据，平均编码长度就是交叉熵：

$$H(p,q)=-\sum_x p(x)\log q(x)$$

约定 $0\log 0=0$。当 $q(x)=0$ 而 $p(x)>0$ 时 $H(p,q)=+\infty$，所以实现时要加平滑。

## 二、原理

### 2.1 交叉熵 = 熵 + KL 散度

推导（在中间加一项再减一项）：

$$\begin{aligned}
H(p,q)&=-\sum_x p(x)\log q(x)\\
&=-\sum_x p(x)\log p(x)+\sum_x p(x)\log\frac{p(x)}{q(x)}\\
&=H(p)+\mathrm{KL}(p\Vert q)\ \ge\ H(p)
\end{aligned}$$

**这就是交叉熵能当损失函数的原因。** 在监督学习中真实分布 $p$（标签）固定不变，所以 $H(p)$ 是与模型无关的常数，于是

$$\min_q H(p,q)\iff\min_q \mathrm{KL}(p\Vert q)$$

即**最小化交叉熵等价于最小化模型分布与真实分布的 KL 散度**。

当标签是 one-hot 硬标签时 $H(p)=0$，损失下界为 0；此时对 $k$ 分类，均匀预测的交叉熵为 $\log k$，可作为"随机猜"的基准。当标签是软标签时 $H(p)>0$，损失下界就是 $H(p)$，不可能降到 0。

### 2.2 为什么不用 MSE

以二分类为例，设 $\hat y=\sigma(z)$。

交叉熵损失对 $z$ 的梯度是

$$\frac{\partial L_{\mathrm{CE}}}{\partial z}=\hat y-y$$

而 MSE 损失对 $z$ 的梯度是

$$\frac{\partial L_{\mathrm{MSE}}}{\partial z}=(y-\hat y)\,\hat y(1-\hat y)$$

对比可见，当模型错得很严重时（例如 $y=1$ 而 $\hat y=0.01$），MSE 的梯度含因子 $\hat y(1-\hat y)=0.0099$ 而趋于 0，**梯度消失**；交叉熵的梯度仍为 $-0.99$，**学习信号饱满**。差约两个数量级。此外交叉熵关于线性权重是凸函数，有唯一全局最优。

## 三、从最大似然推导交叉熵损失

### 3.1 二分类

**建模**：$y\in\{0,1\}$，$\hat y=P(y=1\mid\mathbf x;\mathbf w)=\sigma(\mathbf w^{\mathsf T}\mathbf x)$。把伯努利分布写成一式：

$$P(y\mid\mathbf x;\mathbf w)=\hat y^{\,y}(1-\hat y)^{1-y}$$

**似然**（$N$ 个独立样本）：

$$L(\mathbf w)=\prod_{i=1}^{N}\hat y_i^{\,y_i}(1-\hat y_i)^{1-y_i}$$

**取对数**（乘积变求和）：

$$\log L(\mathbf w)=\sum_{i=1}^{N}\Big[y_i\log\hat y_i+(1-y_i)\log(1-\hat y_i)\Big]$$

最大似然要最大化对数似然，损失函数要最小化，故取负号：

$$L_{\mathrm{BCE}}(\mathbf w)=-\frac1N\sum_{i=1}^{N}\Big[y_i\log\hat y_i+(1-y_i)\log(1-\hat y_i)\Big]$$

这就是二分类交叉熵损失，也就是对数损失。由此可见**交叉熵损失不是人为设计的，而是最大似然估计的必然结果**。

### 3.2 多分类

设 $y\in\{1,\dots,K\}$，用 softmax 输出：

$$\hat y_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}},\qquad z_k=\mathbf w_k^{\mathsf T}\mathbf x$$

把标签写成 one-hot 向量 $\mathbf y$，则 $P(y\mid\mathbf x)=\prod_k\hat y_k^{y_k}$，对数似然为

$$\log L=\sum_{i=1}^{N}\log\hat y_{i,\,y_i}$$

于是多分类交叉熵为

$$L_{\mathrm{CE}}=-\frac1N\sum_{i=1}^{N}\log\hat y_{i,\,y_i}$$

即**真实类别预测概率的负对数**，只有真实类别那一项存活。

### 3.3 梯度推导

**二分类。** 令 $\hat y=\sigma(z)$。先求对 $\hat y$ 的导数：

$$\frac{\partial L}{\partial\hat y}=-\frac{y}{\hat y}+\frac{1-y}{1-\hat y}=\frac{\hat y-y}{\hat y(1-\hat y)}$$

再求 sigmoid 的导数：

$$\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}=\sigma(z)\big(1-\sigma(z)\big)=\hat y(1-\hat y)$$

链式法则中分母恰好被抵消：

$$\frac{\partial L}{\partial z}=\frac{\hat y-y}{\hat y(1-\hat y)}\cdot\hat y(1-\hat y)=\hat y-y$$

$$\frac{\partial L}{\partial\mathbf w}=(\hat y-y)\,\mathbf x$$

**多分类。** 先求 softmax 的雅可比矩阵（分 $k=j$ 与 $k\ne j$ 两种情况）：

$$\frac{\partial\hat y_k}{\partial z_j}=\hat y_k\big(\mathbb 1(k=j)-\hat y_j\big)$$

再代入链式法则：

$$\frac{\partial L}{\partial z_j}=\sum_k\left(-\frac{y_k}{\hat y_k}\right)\hat y_k\big(\mathbb 1(k=j)-\hat y_j\big)=-y_j+\hat y_j\sum_k y_k=\hat y_j-y_j$$

$$\frac{\partial L}{\partial\mathbf z}=\hat{\mathbf y}-\mathbf y,\qquad \frac{\partial L}{\partial\mathbf W}=(\hat{\mathbf y}-\mathbf y)\mathbf x^{\mathsf T}$$

两种情况的梯度形式完全一致，都是"预测减真实"，这是指数族典范链接的一般结论。分母被精确抵消正是**交叉熵必须与 sigmoid/softmax 配对使用**的原因。

> 数值实现注意：softmax 要先减去最大值（利用平移不变性）避免指数溢出；BCE 要用 `logaddexp` 之类的稳定形式避免 $\log 0$。

## 四、数值例子

### 4.1 二分类例子

设 $\mathbf x=(0.5,\ 2.0)^{\mathsf T}$，$\mathbf w=(-0.5,\ 0.5)^{\mathsf T}$，真实标签 $y=1$。

**线性得分：**

$$z=\mathbf w^{\mathsf T}\mathbf x=(-0.5)(0.5)+(0.5)(2.0)=0.75$$

**预测概率：**

$$\hat y=\sigma(0.75)=\frac{1}{1+e^{-0.75}}=0.679179$$

**交叉熵损失：**

$$L=-\big[y\log\hat y+(1-y)\log(1-\hat y)\big]=-\log 0.679179=0.386871$$

换成 bit：$0.386871/\log 2=0.558137$ bit。

**用 KL 分解验证：** 真实分布 $p=(0,1)$，模型分布 $q=(0.320821,\ 0.679179)$。

$$H(p)=-0\log0-1\log1=0,\qquad \mathrm{KL}(p\Vert q)=1\cdot\log\frac{1}{0.679179}=0.386871$$

$$H(p)+\mathrm{KL}(p\Vert q)=0.386871=L\ \checkmark$$

**梯度：**

$$\frac{\partial L}{\partial z}=\hat y-y=-0.320821,\qquad
\frac{\partial L}{\partial\mathbf w}=(\hat y-y)\mathbf x=(-0.160411,\ -0.641643)$$

用中心差分 $\frac{L(w_i+\epsilon)-L(w_i-\epsilon)}{2\epsilon}$（$\epsilon=10^{-7}$）检验，得到完全相同的值，验证梯度推导正确。

### 4.2 多分类例子

设 $\mathbf x=(1.0,\ 0.5)^{\mathsf T}$，$\mathbf W=\begin{bmatrix}0.2&-0.1&0.4\\-0.3&0.5&0.1\end{bmatrix}$（每列为一个类别的权重），真实类别为第 3 类，one-hot 标签 $\mathbf y=(0,0,1)^{\mathsf T}$。

**logits：**

$$\mathbf z=\mathbf W^{\mathsf T}\mathbf x=\big(0.05,\ 0.15,\ 0.45\big)^{\mathsf T}$$

**softmax：**（先减最大值 0.45）

$$e^{-0.40}=0.670320,\quad e^{-0.30}=0.740818,\quad e^{0}=1,\quad \sum=2.411138$$

$$\hat{\mathbf y}=(0.278010,\ 0.307248,\ 0.414742),\qquad \sum_k\hat y_k=1\ \checkmark$$

**交叉熵：**

$$L=-\log\hat y_3=-\log 0.414742=0.880099$$

均匀预测的交叉熵是 $\log 3=1.098612$，因为 $0.880099<1.098612$，模型优于随机猜测。

**梯度：**

$$\frac{\partial L}{\partial\mathbf z}=\hat{\mathbf y}-\mathbf y=(0.278010,\ 0.307248,\ -0.585258)$$

三个分量之和为 0，这反映了 softmax 的平移不变性（输出之和恒为 1）。

$$\frac{\partial L}{\partial\mathbf W}=(\hat{\mathbf y}-\mathbf y)\mathbf x^{\mathsf T}
=\begin{bmatrix}0.278010&0.307248&-0.585258\\0.139005&0.153624&-0.292629\end{bmatrix}$$

逐元素做中心差分（$\epsilon=10^{-6}$）检验，结果完全一致。

### 4.3 $H(p,q)=H(p)+\mathrm{KL}(p\Vert q)$ 的验证

固定真实分布 $p(1)=0.8$，改变模型预测 $q$：

| $q$ | $H(p)$ | $H(p,q)$ | $\mathrm{KL}(p\Vert q)$ | $H(p)+\mathrm{KL}$ |
| --- | --- | --- | --- | --- |
| 0.5 | 0.500402 | 0.693147 | 0.192745 | 0.693147 |
| 0.6 | 0.500402 | 0.591919 | 0.091516 | 0.591919 |
| 0.7 | 0.500402 | 0.526135 | 0.025732 | 0.526135 |
| **0.8** | 0.500402 | **0.500402** | 0.000000 | 0.500402 |
| 0.9 | 0.500402 | 0.544805 | 0.044403 | 0.544805 |

$H(p)$ 恒为 0.500402；交叉熵在 $q=p=0.8$ 处取最小值，最小值恰为 $H(p)$。

## 五、应用

### 5.1 分类任务

| 任务 | 输出层 | 损失 |
| --- | --- | --- |
| 二分类 | sigmoid | 二分类交叉熵 |
| 多分类（互斥） | softmax | 多分类交叉熵 |
| 多标签（不互斥） | 每类 sigmoid | 各类交叉熵之和 |

### 5.2 语言模型与困惑度

语言模型预测下一个词，损失就是交叉熵 $L=-\frac1T\sum_t\log\hat y_{t,w_t}$。定义困惑度

$$\mathrm{PPL}=e^{L}$$

它的直观含义是"模型在每一步平均在多少个候选词之间犹豫"。因为 PPL 是交叉熵的单调函数，最小化交叉熵就是最小化困惑度，这就是大语言模型训练目标的来源。

### 5.3 其他应用

- **知识蒸馏**：用教师模型的软标签 $\mathbf p$ 训练学生模型，$L=-\sum_k p_k\log q_k$。软标签的 $H(p)>0$，携带类间相似性信息，且梯度 $\mathbf q-\mathbf p$ 不会饱和。
- **强化学习**：策略梯度中包含 $\nabla_\theta\log\pi_\theta(a\mid s)$，即策略分布对实际动作的负交叉熵的梯度；熵正则项 $H(\pi)$ 鼓励探索。
- **变分推断**：ELBO 中的重构项就是负交叉熵，VAE 的损失函数即重构项加 KL 项。
- **恰当评分规则**：交叉熵是恰当评分规则，即报出真实分布时期望损失最小，因此模型没有动机隐藏真实置信度（准确率不具备这个性质）。
- **常见改进**：类别不平衡用 Focal Loss $L=-\alpha_t(1-\hat y_t)^\gamma\log\hat y_t$；过度自信用标签平滑或温度缩放 $q_k\propto e^{z_k/T}$ 校准。

## 附：验证代码

```python
import numpy as np
sigmoid = lambda t: 1 / (1 + np.exp(-t))       # 逻辑斯蒂函数

# ---------- 二分类例子 ----------
x, w, y = np.array([0.5, 2.0]), np.array([-0.5, 0.5]), 1.0
z = w @ x                                      # 线性得分
p = sigmoid(z)                                 # 预测概率
L = -(y * np.log(p) + (1 - y) * np.log(1 - p)) # 交叉熵损失
print(f"z={z:.6f}  p={p:.6f}  损失={L:.6f} nat = {L/np.log(2):.6f} bit")
print("dL/dz =", p - y)                        # -0.320821
print("dL/dw =", (p - y) * x)                  # [-0.160411 -0.641643]

# 用中心差分检验梯度
eps  = 1e-7
loss = lambda ww: -(y * np.log(sigmoid(ww @ x)) + (1 - y) * np.log(1 - sigmoid(ww @ x)))
fd   = [(loss(w + eps * np.eye(2)[i]) - loss(w - eps * np.eye(2)[i])) / (2 * eps) for i in range(2)]
print("差分梯度 =", fd)                         # 与解析梯度一致

# ---------- 三分类 softmax 例子 ----------
W   = np.array([[0.2, -0.1, 0.4], [-0.3, 0.5, 0.1]])   # 2 个特征 × 3 个类别
xs  = np.array([1.0, 0.5])                              # 输入
cls = 2                                                 # 真实类别（0 起算）
lg  = W.T @ xs                                          # logits
pr  = np.exp(lg - lg.max()); pr = pr / pr.sum()         # 减最大值后再做 softmax
print("logits =", lg, " softmax =", pr, " 之和 =", pr.sum())
print(f"交叉熵 = {-np.log(pr[cls]):.6f}   随机基准 log3 = {np.log(3):.6f}")

g = pr.copy(); g[cls] -= 1                              # 对 logits 的梯度 = 预测 - 真实
print("dL/dz =", g, " 分量和 =", g.sum())
print("dL/dW =\n", np.outer(g, xs).T)                    # 外积形式

# 逐元素中心差分检验 dL/dW
def ce_of(WW):
    e = np.exp((WW.T @ xs) - (WW.T @ xs).max())
    return -np.log((e / e.sum())[cls])
fdW = np.zeros_like(W)
for i in range(2):
    for j in range(3):
        Wp, Wm = W.copy(), W.copy()
        Wp[i, j] += 1e-6; Wm[i, j] -= 1e-6
        fdW[i, j] = (ce_of(Wp) - ce_of(Wm)) / 2e-6
print("差分 dL/dW =\n", fdW)

# ---------- 验证 H(p,q) = H(p) + KL(p||q) ----------
pt = 0.8                                                # 真实分布 p(1)=0.8
Hp = -(pt * np.log(pt) + (1 - pt) * np.log(1 - pt))      # 真实分布的熵
for q in [0.5, 0.6, 0.7, 0.8, 0.9]:
    CE = -(pt * np.log(q) + (1 - pt) * np.log(1 - q))    # 交叉熵
    KL = pt * np.log(pt / q) + (1 - pt) * np.log((1 - pt) / (1 - q))   # KL 散度
    print(f"q={q}: CE={CE:.6f}  H(p)+KL={Hp+KL:.6f}  KL={KL:.6f}")
```
