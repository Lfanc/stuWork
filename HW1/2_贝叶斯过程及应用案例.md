# 贝叶斯过程及其应用案例

## 一、贝叶斯过程的基本思想与流程

贝叶斯方法把**未知参数看作随机变量**，用先验分布表示看到数据前的认识，用似然函数吸收数据信息，得到后验分布，再由后验分布做预测和决策：

$$p(\theta\mid D)=\frac{p(D\mid\theta)\,p(\theta)}{p(D)},\qquad p(D)=\int p(D\mid\theta)p(\theta)\,\mathrm d\theta$$

四个组成部分：

| 名称 | 记号 | 含义 |
| --- | --- | --- |
| 先验 | $p(\theta)$ | 看数据前的信念 |
| 似然 | $p(D\mid\theta)$ | 数据的生成机制 |
| 证据 | $p(D)$ | 归一化常数，与 $\theta$ 无关 |
| 后验 | $p(\theta\mid D)$ | 更新后的信念 |

实际计算中只用比例形式（因为证据不含 $\theta$）：

$$p(\theta\mid D)\propto p(D\mid\theta)\,p(\theta)$$

**建模流程**：明确变量 → 写似然 → 设先验 → 求后验 → 求后验预测分布 → 据此决策。

**"过程"的含义**：贝叶斯更新可以递推，今天的后验就是明天的先验：

$$p(\theta\mid D_1,D_2)\propto p(D_2\mid\theta)\,p(\theta\mid D_1)$$

因此新数据到来时不必重放旧数据，适合流式场景。推断的最终目标是**后验预测分布**

$$p(y_*\mid x_*,D)=\int p(y_*\mid x_*,\theta)\,p(\theta\mid D)\,\mathrm d\theta$$

这个积分体现了贝叶斯与点估计（只算 $p(y_*\mid x_*,\hat\theta)$）的本质区别。

## 二、应用案例：代码变更的缺陷风险预测

### 2.1 问题背景

某项目用 CI/CD 流水线，每次代码合并前需要判断**这次变更引入缺陷的概率**，以决定是否追加代码评审。历史标注数据只有 8 条（实际项目约 200 条，这里为便于手算取 8 条），属于小样本问题，且特征与标签几乎完全可分——这类情况下最大似然估计会发散，因此采用贝叶斯方法。

### 2.2 变量定义

**响应变量** $y\in\{0,1\}$：该次变更是否引入缺陷。

**特征**（$d=3$ 个业务特征 + 1 个偏置项，记为 $\mathbf x=(1,x_1,x_2,x_3)^{\mathsf T}$）：

| 符号 | 含义 | 处理 |
| --- | --- | --- |
| $x_1$ | 变更规模（增删代码行数） | 取 $\log(1+\text{LOC})$ 后标准化 |
| $x_2$ | 新增代码的测试覆盖率 | 归一到 $[0,1]$ |
| $x_3$ | 圈复杂度增量 | 标准化 |

规模取对数是因为它的影响是乘性的。

### 2.3 第 1 步：似然建模

设 $y_i$ 服从伯努利分布，成功概率由特征的逻辑斯蒂函数给出：

$$y_i\mid\mathbf w\ \sim\ \mathrm{Bernoulli}(\pi_i),\qquad \pi_i=\sigma(\mathbf w^{\mathsf T}\mathbf x_i)=\frac{1}{1+e^{-\mathbf w^{\mathsf T}\mathbf x_i}}$$

用 logistic 链接的理由：$\pi_i\in(0,1)$ 自动满足概率约束；$\log\frac{\pi_i}{1-\pi_i}=\mathbf w^{\mathsf T}\mathbf x_i$ 使系数可解释为"特征每增加一单位，对数几率增加 $w_j$"；且它是广义线性模型的典范链接，保证似然是凹函数。

似然与对数似然：

$$p(D\mid\mathbf w)=\prod_{i=1}^{N}\pi_i^{y_i}(1-\pi_i)^{1-y_i}$$

$$\mathcal L(\mathbf w)=\sum_{i=1}^{N}\Big[y_i\,\mathbf w^{\mathsf T}\mathbf x_i-\log\big(1+e^{\mathbf w^{\mathsf T}\mathbf x_i}\big)\Big]$$

（第二式是把 $\log\pi_i$ 展开得到的数值稳定形式，它等于负的交叉熵损失。）

梯度为

$$\nabla\mathcal L(\mathbf w)=X^{\mathsf T}(\mathbf y-\boldsymbol\pi),\qquad \nabla^2\mathcal L(\mathbf w)=-X^{\mathsf T}\mathbf WX,\quad \mathbf W=\operatorname{diag}\big(\pi_i(1-\pi_i)\big)$$

因 $\mathbf W$ 正定，$\mathcal L$ 是凹函数，后验有唯一众数。

### 2.4 第 2 步：先验建模

取各分量独立的高斯先验：

$$\mathbf w\sim\mathcal N(\mathbf 0,\ \alpha^{-1}I_d),\qquad p(\mathbf w)=\left(\frac{\alpha}{2\pi}\right)^{d/2}\exp\!\left(-\frac{\alpha}{2}\lVert\mathbf w\rVert^2\right)$$

取 $\alpha=1$ 的业务含义：系数落在 $[-2,2]$ 内的先验概率约 95%，即"单个特征最多把缺陷几率放大 $e^2\approx7.4$ 倍"，这是工程上可接受的最强效应。

先验有两个数学作用：

1. **解决可分行问题**。若数据完全可分，MLE 的解不存在（$\mathcal L$ 沿某方向趋于无穷），而加了先验后

$$\widehat{\mathbf w}_{\mathrm{MAP}}=\arg\max_{\mathbf w}\Big[\mathcal L(\mathbf w)-\frac{\alpha}{2}\lVert\mathbf w\rVert^2\Big]$$

必有有限解。本文的 8 个样本恰好完全可分，数值实验中 MLE 迭代 300 次后 $\lVert\mathbf w\rVert$ 达到 $2097.6$ 仍在发散，而 MAP 稳定在 $1.096$。

2. **MAP 解就是 $L_2$ 正则化的逻辑回归（岭回归）**。这说明"正则化"在贝叶斯视角下就是"先验"，而且 $\alpha$ 可以由证据最大化自动学出，不必手工调参。

### 2.5 第 3 步：后验分布与 Laplace 近似

后验为

$$p(\mathbf w\mid D)\propto\exp\!\left(\mathcal L(\mathbf w)-\frac{\alpha}{2}\lVert\mathbf w\rVert^2\right)$$

逻辑回归没有共轭先验，分母的 $d$ 维积分无闭式解。这里采用 **Laplace 近似**：先找后验众数，再在众数处做二阶泰勒展开。

**（1）求众数。** 令 $\nabla\log p(\mathbf w\mid D)=X^{\mathsf T}(\mathbf y-\boldsymbol\pi)-\alpha\mathbf w=\mathbf 0$，用牛顿–拉弗森法迭代：

$$\mathbf w^{\text{new}}=\mathbf w+\Big(X^{\mathsf T}\mathbf WX+\alpha I\Big)^{-1}\Big[X^{\mathsf T}(\mathbf y-\boldsymbol\pi)-\alpha\mathbf w\Big]$$

**（2）二阶展开。** 记 $f(\mathbf w)=\log p(\mathbf w\mid D)$，因 $\nabla f(\widehat{\mathbf w})=\mathbf 0$，

$$f(\mathbf w)\approx f(\widehat{\mathbf w})+\frac{1}{2}(\mathbf w-\widehat{\mathbf w})^{\mathsf T}\nabla^2 f(\widehat{\mathbf w})(\mathbf w-\widehat{\mathbf w})$$

归一化后得高斯近似：

$$p(\mathbf w\mid D)\ \approx\ \mathcal N\big(\widehat{\mathbf w},\ \mathbf S_N\big),\qquad
\mathbf S_N=\Big(X^{\mathsf T}\mathbf W_NX+\alpha I\Big)^{-1}$$

其中 $\mathbf W_N$ 在 $\widehat{\mathbf w}$ 处取值。**后验均值就是 MAP 估计，后验协方差量化了参数的不确定性**。

### 2.6 第 4 步：后验预测分布

对新的变更 $\mathbf x_*$，缺陷概率的完整分布为

$$p(y_*=1\mid\mathbf x_*,D)=\int \sigma(\mathbf w^{\mathsf T}\mathbf x_*)\,\mathcal N(\mathbf w\mid\widehat{\mathbf w},\mathbf S_N)\,\mathrm d\mathbf w$$

这个积分没有闭式解，用蒙特卡洛计算：对 $\mathbf S_N$ 做 Cholesky 分解 $\mathbf S_N=LL^{\mathsf T}$，抽 $M$ 个样本

$$\mathbf w^{(m)}=\widehat{\mathbf w}+L\boldsymbol\epsilon^{(m)},\quad \boldsymbol\epsilon^{(m)}\sim\mathcal N(\mathbf 0,I),\qquad
p(y_*=1)\approx\frac1M\sum_{m=1}^{M}\sigma\big(\mathbf w^{(m)\mathsf T}\mathbf x_*\big)$$

也可以解析地用 probit 近似得到收缩形式（$\kappa$ 为收缩因子）：

$$p(y_*=1)\approx\sigma\big(\kappa\cdot\widehat{\mathbf w}^{\mathsf T}\mathbf x_*\big),\qquad
\kappa=\left(1+\frac{\pi}{8}\mathbf x_*^{\mathsf T}\mathbf S_N\mathbf x_*\right)^{-1/2}$$

$\kappa\to1$ 表示参数不确定性小、退化为点估计；$\kappa\to0$ 表示参数很不确定、预测被拉回 0.5，即**模型知道自己不知道什么**。

### 2.7 数值结果

训练数据（特征已标准化）：

| 样本 | $x_1$ 规模 | $x_2$ 覆盖率 | $x_3$ 复杂度 | $y$ |
| --- | --- | --- | --- | --- |
| 1 | 0.35 | 0.85 | 0.30 | 0 |
| 2 | 0.90 | 0.20 | 0.75 | 1 |
| 3 | 0.55 | 0.60 | 0.45 | 0 |
| 4 | 0.75 | 0.35 | 0.65 | 1 |
| 5 | 0.20 | 0.90 | 0.25 | 0 |
| 6 | 1.10 | 0.10 | 0.85 | 1 |
| 7 | 0.45 | 0.70 | 0.40 | 0 |
| 8 | 0.65 | 0.45 | 0.55 | 1 |

**牛顿迭代**（$\alpha=1$，初值 $\mathbf w=\mathbf 0$）：3 次迭代后梯度范数降到 $10^{-5}$ 以下，5 次到机器精度，收敛很快。

**MAP 估计**：

$$\widehat{\mathbf w}=(-0.1272,\ 0.5963,\ -0.7910,\ 0.4513)$$

符号与业务直觉一致：变更规模、复杂度增大则风险升高，覆盖率提高则风险降低。

**后验标准差**：

$$\sqrt{\operatorname{diag}(\mathbf S_N)}=(0.7667,\ 0.8756,\ 0.8737,\ 0.9213)$$

标准差与系数同量级，说明 8 个样本远远不够，参数很不确定——这是 MLE 无法提供的信息。

**系数 $w_1$ 的不确定性**：$w_1=0.5963$，后验 95% 可信区间为 $[-1.1199,\ 2.3126]$，$P(w_1>0\mid D)\approx0.75$。因此只能说"有中等证据（约 75% 概率）支持变更规模正效应"，不能宣称显著。

**新变更预测**：取 $\mathbf x_*=(1,\ 0.80,\ 0.25,\ 0.70)^{\mathsf T}$（大变更、低覆盖率）。

$$\widehat{\mathbf w}^{\mathsf T}\mathbf x_*=0.4680,\qquad
\mathbf x_*^{\mathsf T}\mathbf S_N\mathbf x_*=0.5356,\qquad
\kappa=0.9090$$

| 方法 | 公式 | 缺陷概率 |
| --- | --- | --- |
| 点估计 | $\sigma(z_*)$ | 0.6149 |
| 贝叶斯预测（probit） | $\sigma(\kappa z_*)$ | 0.6048 |
| 贝叶斯预测（蒙特卡洛，40 万次） | 式 2.6 求和 | 0.6032 |

95% 预测区间为 $[0.2754,\ 0.8702]$。区间很宽，说明单点预测不可靠；点估计 0.6149 略微高估，贝叶斯预测更保守。

**决策**：若追加评审成本 2 工时、漏掉缺陷的期望成本 20 工时，则当 $p>0.1$ 时应强制评审。$0.6032>0.1$，且区间下界 $0.2754$ 也大于 $0.1$，结论稳健。

**与 MLE 对比**（同一数据）：

| 方法 | 正则强度 | 迭代次数 | $\lVert\mathbf w\rVert$ | 收敛 |
| --- | --- | --- | --- | --- |
| MLE | $\alpha=0$ | 300（上限） | 2097.595 | 发散（完全可分） |
| 贝叶斯 MAP | $\alpha=1$ | 5 | 1.096 | 稳定 |

### 2.8 案例小结

贝叶斯方法在本案例中的作用有三点：一是**高斯先验让完全可分数据的估计问题变得良定**（$\lVert\mathbf w\rVert$ 从 2097.6 降到 1.096），二是**后验协方差给出了每个系数的可信度**，能诚实地报告"数据不足"，三是**后验预测分布支撑了带风险意识的决策**（收缩因子 $\kappa=0.9090$ 把 0.6149 修正为 0.6032，并给出 $[0.275,0.870]$ 的区间）。当样本量增大时，先验影响会自动衰减，贝叶斯结果趋近于频率派结果。

## 附：验证代码

```python
import numpy as np
rng = np.random.default_rng(20240501)          # 固定随机种子，保证结果可复现

# 训练数据：第 1 列为偏置项，其余为三个特征
X = np.array([[1, .35, .85, .30], [1, .90, .20, .75],
              [1, .55, .60, .45], [1, .75, .35, .65],
              [1, .20, .90, .25], [1, 1.10, .10, .85],
              [1, .45, .70, .40], [1, .65, .45, .55]], dtype=float)
y = np.array([0, 1, 0, 1, 0, 1, 0, 1], dtype=float)

d, alpha, w = X.shape[1], 1.0, np.zeros(4)     # d 为特征维数，alpha 为先验精度

# 牛顿-拉弗森迭代求后验众数（即 MAP 估计）
for it in range(12):
    mu = 1 / (1 + np.exp(-X @ w))              # 逻辑斯蒂预测概率
    W  = mu * (1 - mu)                         # 加权矩阵对角元
    g  = X.T @ (y - mu) - alpha * w            # 后验对数梯度
    H  = -(X.T @ (X * W[:, None])) - alpha * np.eye(d)   # 后验对数 Hessian
    step = np.linalg.solve(H, -g)              # 牛顿步长
    w = w + step
    if np.max(np.abs(step)) < 1e-12:           # 收敛判据
        break
print("MAP 估计:", w)                          # [-0.1272 0.5963 -0.7910 0.4513]

# Laplace 近似的后验协方差
S_N = np.linalg.inv(X.T @ (X * W[:, None]) + alpha * np.eye(d))
print("后验标准差:", np.sqrt(np.diag(S_N)))     # [0.7667 0.8756 0.8737 0.9213]

# 对新变更做后验预测
x_star = np.array([1, .80, .25, .70])
z      = x_star @ w                            # 线性得分
var_z  = x_star @ S_N @ x_star                 # 得分上的参数不确定性
kappa  = 1 / np.sqrt(1 + np.pi * var_z / 8)    # probit 近似的收缩因子
print("点估计预测:", 1 / (1 + np.exp(-z)))       # 0.6149
print("贝叶斯预测:", 1 / (1 + np.exp(-kappa * z)))  # 0.6048

# 蒙特卡洛验证：从后验协方差抽样，再对预测概率求平均
L  = np.linalg.cholesky(S_N)                   # S_N = L L^T
ws = w + rng.standard_normal((400000, d)) @ L.T
ps = 1 / (1 + np.exp(-(ws @ x_star)))
print("蒙特卡洛预测:", ps.mean())               # 0.6032
print("95% 预测区间:", np.percentile(ps, [2.5, 97.5]))   # [0.2754 0.8702]
print("P(w1>0|D):", (ws[:, 1] > 0).mean())     # 约 0.75
```
