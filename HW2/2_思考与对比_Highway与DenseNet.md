# 作业 2：Highway Network、DenseNet 与 ResNet 的对比

## 一、Highway Network vs ResNet

### 1. 结构公式

**Highway**（Srivastava et al., 2015）

$$
y=H(x,W_H)\odot T(x,W_T)+x\odot C(x,W_C),\qquad T=\sigma(W_Tx+b_T),\quad C=1-T
$$

**ResNet**（He et al., 2016）

$$
y=x+F(x,W)
$$

两者都用一个跨层短路把输入直接送到输出；差别只在**短路是被"门控"调制的，还是无条件直连的**。

### 2. 逐项对比

| 维度      | Highway Network                              | ResNet                                    |
| ------- | -------------------------------------------- | ----------------------------------------- |
| 短路实现    | 门控加权相加：$T\odot H+C\odot x$，门 $T$ 由**输入数据**决定 | 无门控的恒等相加：$x+F$                            |
| 额外参数    | 有，门控约多一倍参数（$W_T,b_T$）                        | 无（仅维度不匹配时用 $1\times1$ 卷积投影）               |
| 主干信号    | 被 $C(x)\in(0,1)$ 逐元素**缩放**，$C\to0$ 时主干被关掉    | 系数恒为 $1$，恒等映射是结构自带的                       |
| 梯度通路    | 梯度乘 $C$ 与 $\sigma'$，仍可能被门控衰减                 | $(1+\partial F/\partial x)$ 中的 $1$ 恒定，不衰减 |
| 恒等映射的取得 | 需靠学习，并靠 $b_T$ 取负值初始化来"偏置"成近似恒等               | 天然获得，$F\to0$ 即可                           |
| 典型场景    | 全连接网络为主                                      | 卷积网络（ResNet-50/101/152）                   |

### 3. 总结

ResNet 可看作 Highway 在 $T\equiv C\equiv1$、并去掉门控参数后的**退化情形**：门控被删掉，恒等映射从"要学会的东西"变成"结构免费提供的东西"。代价是表达能力略降，收益是参数更少、优化更稳、可直接推广到卷积与上百层的结构——这也是 ResNet 在 ImageNet 上胜出并成为主流的直接原因。

## 二、DenseNet vs ResNet

### 1. 连接方式的本质区别

**ResNet：相加（summation）**

$$
x_l=x_{l-1}+F(x_{l-1})\quad\Longrightarrow\quad x_l=x_0+\sum_{i<l}F(x_i)
$$

历史信息被**折叠**进同一组通道里逐次累加。

**DenseNet：拼接（concatenation）**

$$
x_l=H_l\left([x_0,x_1,\dots,x_{l-1}]\right)
$$

前面所有层的特征图沿通道维拼接后一起送入当前层，第 $l$ 层有 $k_0+k\,(l-1)$ 个输入通道（$k$ 为 growth rate）。

> 本质差异：**相加是"覆盖式融合"**——同位置的旧特征会被新特征数值上改写，信息混在一起、不可再分离；**拼接是"保留式追加"**——旧特征原样保留，只是接了新的通道，每层都能直接读到原始的浅层特征。

### 2. 优缺点

|         | ResNet              | DenseNet                 |
| ------- | ------------------- | ------------------------ |
| 聚合算子    | 逐元素相加               | 通道拼接                     |
| 输入来源    | 上一层（identity 中的累积量） | 所有前面层                    |
| 通道数     | 不变                  | 随深度线性增长                  |
| 参数量     | 较大（靠加宽通道提精度）        | 小很多（层很窄，$k=12\sim32$）    |
| 显存 / 计算 | 较低                  | 高（所有特征图都要留到反向传播）         |
| 梯度通路    | $2^{L-l}$ 条路径之和     | 每层到 loss 的通路数随 $l$ 组合式增长 |

**DenseNet 的优点**

- 梯度可沿全部拼接路径回传，缓解梯度消失比 ResNet 更彻底；
- **显式特征复用**：浅层边缘/纹理不会被深层覆盖，因此每层只需学少量新特征，参数效率极高（同精度下参数量常为 ResNet 的几分之一）；
- 拼接带来的随机性有正则效果，小数据集上更不易过拟合。

**DenseNet 的缺点**

- **显存与带宽开销大**：通道数线性膨胀，concat 与大量小卷积对硬件不友好，训练/推理显存占用高；
- 结构更复杂：必须插 transition layer（$1\times1$ 卷积 + 平均池化）把通道压回一半，超参更多；
- 推理延迟高，部署不如 ResNet 方便（ResNet 结构规整、易剪枝量化）。

### 3. 一句话总结

ResNet 用"加法"换来一条系数为 $1$ 的梯度高速路，网络等价于多条不同深度浅路径的集成；DenseNet 用"拼接"换来极致的特征复用与参数效率，代价是把开销从参数转移到了显存和带宽上。
